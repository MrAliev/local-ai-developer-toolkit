# Политика подписи кода

[English version](code-signing-policy.md)

Эта политика регулирует Authenticode-подпись бинарников LocalAi. Она вступает в силу с
первым подписанным релизом и публикуется заранее — как часть заявки проекта в программу
SignPath Foundation для open source.

Бесплатную подпись кода предоставляет [SignPath.io](https://signpath.io), сертификат —
[SignPath Foundation](https://signpath.org).

## Что подписывается

- `LocalAi.Installer.exe` — файл, который запускает пользователь;
- шесть исполняемых файлов внутри релизного пакета: `LocalAi.Broker.exe`,
  `codesearch-mcp.exe`, `locallm-mcp.exe`, `codesearch.exe`, `localai.exe`,
  `localai-launcher.exe`.

Больше под эту политику не подписывается ничего. Манифест релиза сохраняет свою отдельную
подпись ECDSA P-256, которую установщик сверяет с вшитым в него ключом: Authenticode
защищает загрузку, подпись манифеста — всё, что установщик скачивает после.

## Откуда берутся подписанные бинарники

Подписанные бинарники собираются GitHub Actions из помеченного тегом релизного коммита
[этого репозитория](https://github.com/MrAliev/local-ai-developer-toolkit) и
подписываются через SignPath, поэтому каждый подписанный артефакт прослеживается до
публичных исходников. Бинарники, собранные где-либо ещё — включая машину мейнтейнера, —
на подпись не отправляются никогда. Атрибуты имени продукта и версии задаются при сборке
из версии релиза.

## Приватность

LocalAi запускает локальные модели на машине самого пользователя; код, логи и
изображения, отданные этим моделям, её не покидают. Рантайм пишет телеметрию заданий
локально, и в ней никогда нет промптов, содержимого файлов, путей и секретов — полная
формулировка в [SECURITY.ru.md](../SECURITY.ru.md) и разделе телеметрии
[обзора для разработчиков](overview.ru.md). Установщик ничего не собирает и никуда не
звонит; вся его работа с сетью — скачивание релиза, который он проверяет.

## Что установщик делает с машиной

Каждое изменение мастер показывает на странице подтверждения до того, как что-либо
применить, и каждый прогон пишет журнал намерений и исходов в
`%LOCALAPPDATA%\LocalAi-installer-logs`. Неудачный или отменённый прогон предлагает откат
всего доказуемо обратимого. Удаление: удалить `%LOCALAPPDATA%\LocalAi`, убрать две
регистрации MCP-серверов из конфигурационных файлов AI-клиентов и удалить управляемый
блок инструкций между его явными маркерами в этих файлах; пререквизиты, поставленные
через winget, удаляются через winget, модели — через Ollama.
