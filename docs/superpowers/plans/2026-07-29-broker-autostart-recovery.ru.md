# План реализации автоматического восстановления брокера

[English version](2026-07-29-broker-autostart-recovery.md)

> **Для агентских работников:** ТРЕБОВАТЕЛЬНЫЙ ПОД-СКИЛ: Используйте суперсилы: subagent-driven-development (рекомендуется) или superpowers:executing-plans для реализации этой задачи пошагово. Шаги используют синтаксис флажков (`- [ ]`) для отслеживания.

**Цель:** Делать клиентов LocalAi автоматически восстанавливаться, когда устаревшее состояние брокера указывает на отсутствующий, повторно используемый или недоступный процесс Windows.

**Архитектура:** Оставьте `EnsureRunningAsync` как единую точку входа для автозапуска. Отвергайте устаревшие данные сердечного биения перед проверкой записанного PID, преобразуйте сбои проверки процесса `Win32Exception` в неисправный результат и оставьте именованный семафор как единственный зажог.

**Стек технологий:** .NET 10, xUnit v3, API-процессов Windows, именованные семафоры.
