# План разбора issue после 0.1.45

[English version](2026-08-28-post-0-1-45-issue-backlog.md)

**Цель:** закрыть двенадцать issue, открытых после 0.1.45, по одному pull request
на issue, каждый — от `main`.

**Порядок:** первой идёт та, из-за которой сломанный продукт попал в `main` на
зелёной сборке. Затем два дефекта, доставляющие молчаливый отказ на машину
пользователя. Затем набор `p2`, затем `p3`. Issue #139-#142 пришли из бенчмарка
выпущенной сборки и встроены в тот же список, а не дописаны в конец.

## Что показала сортировка

Две из неразобранных issue — не то, чем их считают отчёты, а одна пара имеет
общую первопричину. Оба вывода меняют порядок.

**#143 и #139 — одна и та же слепая зона.** `BuildSemanticIndexAsync` в
`src/LocalAi.Cli/CodeSearchSyncCommand.cs` отправляет любой отказ Roslyn в
консольную диагностику и продолжает работу: null-workspace откатывается к
пустому семантическому индексу, а workspace, все проекты которого не
загрузились, даёт индекс без единого символа C#. И то и другое — пути успеха.
Ни код возврата, ни набор тестов не отличают «проиндексирована семантика C#» от
«не проиндексировано ничего» — поэтому разъехавшиеся версии пакетов прошли 1875
тестов, и поэтому же вероятнее всего single-file `localai.exe sync` печатает
«Dll was not found.» и возвращает 0.

**#140 — не общий хэндл libgit2.** Гонки не на чем устраивать: объекта
`Repository` там нет. `RepoLocator.RunGit` запускает дочерний процесс `git` с
фиксированным сроком `GitTimeoutMs = 10_000` и сворачивает таймаут, отказ
запуска и ненулевой код возврата одинаково в `null`; вызывающая сторона
показывает этот `null` как «Git common directory is unavailable». Шесть
одновременных клиентов на загруженной машине — ровно тот случай, когда
десятисекундный срок не выдерживается, и именно срок объясняет, почему повтор
всегда срабатывал. Это собственное правило репозитория «не проверять, насколько
быстра машина», нарушенное в рабочем коде, а не в тесте.

Порядок устоял, а три диагноза из issue — нет, и каждый оказался ценнее самой починки: #140 был

видимой с двух сторон. Две из трёх назвал раздел сортировки в самом плане; третья прояснилась
только при воспроизведении.

## Правила, которым подчиняется каждая из этих работ

- Одна тема на pull request, ветка от `main`, без наслоения одного PR на другой.
- Тесты ждут наступления условия, а не истечения срока; поиск зависаний — дело
  таймаута прогона в CI.
- Ollama — только через общий брокер.
- Каждый документ существует на английском и русском и ссылается на пару.
- Документация — UTF-8 без BOM, CRLF.
- Комментарии объясняют почему, а не что.
- `dotnet test LocalAi.slnx --configuration Release --max-parallel-test-modules 1
  --timeout 20m`; модули идут по одному, потому что делят именованные мьютексы и
  один каталог рантайма.
