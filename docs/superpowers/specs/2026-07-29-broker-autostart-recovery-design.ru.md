# Дизайн автозапуска брокера

## Проблема

После перезагрузки или некорректного завершения работы клиента файл `host.json` может продолжать существовать после процесса LocalAi брокера. Windows позже может повторно использовать записанный PID для защищенного процесса. Текущие проверки работоспособности сначала проверяют этот PID, а затем сердцебиение, и позволяет исключиться `Win32Exception`. Нормальная операция клиента, следовательно, не начинается автоматически, а завершается ошибкой.

## Желаемое поведение

- Отсутствующий, неправильно сформированный, устаревший, несоответствующий или недоступный брокерский статус считается неисправным.
- Устаревшее сердцебиение отвергается до проверки любых процессов операционной системы.
- Ошибки при проверке процесса не выходят из проверки работоспособности.
- `EnsureRunningAsync` запускает брокер один раз под существующим именованным семафором и ожидает свежего соответствующего состояния.
- Codex и Claude уведомляют пользователя, когда начинается восстановление, но не запрашивают разрешения для обычного старта брокера LocalAi.

## Дизайн

`BrokerProcess.IsHealthy` сначала проверит схему и сердцебиение. Только свежее состояние может достичь внедренной проверки процесса. Вызов метода обернется таким образом, что `Win32Exception` означает, что удостоверить идентификацию процесса не удалось, и состояние неправильное. Существующий семафор старта остается единичной координационной схемой, поэтому для этого не требуется новый сервис, запланированная задача или фоновый наблюдатель.

Уведомление пользователя является правилом рабочего процесса агента, а не выводом клиента брокера. MCP stdout зарезервирован для JSON-RPC и должен остаться свободным от диагностического текста.

## Верификация

Регрессионные тесты охватят:

1. Устаревшее состояние, чей процессный проб из-за чего выбросит исключение, будет отброшено без проверки.
2. Свежее состояние, чей процессный проб выбросит исключение, будет обработано как неправильное и вызовет одно успешное повторное запуск.
3. Существующая здоровая перезагрузка, ограниченный таймаут и поведение при одновременном старте остаются зелеными.

После того, как пройдут фокусированные тесты, будет протестировано полное решение. Исправленные артефакты будут установлены для Codex и Claude, после чего произойдет синхронизация оверлея CodeSearch для плагина Jira.
