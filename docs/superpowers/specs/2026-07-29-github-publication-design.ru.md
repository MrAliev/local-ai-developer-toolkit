# Дизайн публикации Local AI Developer Toolkit

**Дата:** 2026-07-29

## Цель

Опубликовать существующее решение LocalAi в виде приватного личного GitHub-репозитория
`MrAliev/local-ai-developer-toolkit` с синхронизированной вводной документацией на
английском и русском языках.

## Область изменений

- Не изменять имя решения, имена проектов, пространства имён, команды и runtime-пути.
- Представить продукт в документации под именем **Local AI Developer Toolkit**.
- Переписать `README.md` как английский оригинал.
- Переписать `README.ru.md` как его полный русский перевод.
- Создать приватный GitHub-репозиторий в подтверждённой личной учётной записи `MrAliev`.
- Отправить существующую локальную ветку `main` и настроить для неё отслеживание
  `origin/main`.

Переименование исходных проектов и публикация бинарных файлов не входят в эту доработку.

## Структура README

Оба README будут использовать одинаковый порядок разделов:

1. Название продукта, одно предложение о назначении и переключатель языка.
2. Основные возможности: надёжный FIFO-брокер, CodeSearch, интеграция MCP и индексация
   на основе поколений с overlays рабочих деревьев.
3. Обзор компонентов с границами брокера, синхронизации репозитория, CodeSearch и LocalLm.
4. Предварительные требования и краткий быстрый старт.
5. Команды сборки, тестирования и публикации исполняемых файлов.
6. Гарантии runtime и безопасности.
7. Состав проектов и правила разработки.

Английский файл является исходным документом. Русский файл представляет собой полный
синхронизированный перевод, а не сокращённое изложение. Команды, идентификаторы, пути
к файлам и имена компонентов продукта остаются одинаковыми в обеих версиях.

## Процесс публикации

1. Обновить и сопоставить парные README.
2. Сохранить окончания строк Windows CRLF и кодировку UTF-8 без BOM.
3. Запустить полный набор тестов решения и проверить Git diff.
4. Закоммитить только документацию и одобренные артефакты публикации.
5. Создать приватный репозиторий `MrAliev/local-ai-developer-toolkit`.
6. Добавить его как `origin` и отправить локальную `main`.
7. Проверить владельца, видимость, ветку по умолчанию, отслеживание remote и чистоту
   локальной рабочей копии.

Если создание репозитория завершится успешно, но последующий push завершится ошибкой,
приватный репозиторий сохраняется, а вместо удаления внешнего состояния сообщается
точная команда восстановления.

## Критерии приёмки

- Адрес репозитория: `https://github.com/MrAliev/local-ai-developer-toolkit`.
- GitHub показывает приватный репозиторий с владельцем `MrAliev`.
- `README.md` и `README.ru.md` являются полными синхронизированными языковыми версиями.
- Решение по-прежнему проходит полный набор тестов.
- Локальная `main` отслеживает `origin/main`, а после публикации рабочая копия чистая.
