# LocalAi 0.1.16

[Русская версия](0.1.16.ru.md)

## Hotfix

- Direct embedding, direct chat, and native model requests now register the model as resident.
- The broker now checks the backend for managed idle models when the queue is empty even if an
  earlier request did not leave a resident-model marker.
- With the default `IdleModelKeepAliveSeconds=0` policy, CodeSearch embedding models are unloaded
  immediately after the queue has no compatible work instead of remaining in VRAM until Ollama's
  own expiration time.

## Root cause

Idle unloading used the routed-chat resident-model marker as its guard. Direct embedding requests
were executed through a separate path and never updated that marker, so an empty queue looked as
if no model was loaded. The hotfix tracks all model-bearing direct requests and retains a defensive
empty-queue backend check.

## Validation

  resident marker.
