# LocalAi 0.1.19

[Русская версия](0.1.19.ru.md)

## Fixed

- CodeSearch base and overlay embedding builds now persist every completed batch in an atomic,
  write-through checkpoint. After a process interruption or machine restart, the next sync
  restores those vectors and recomputes only the batch that was still active.
- Repository progress is written through before atomic replacement. Corrupted or truncated
  progress JSON is treated as unavailable status instead of crashing the CodeSearch MCP server.

## Added

- `localai sync --base-only` publishes a new base generation without automatically rebuilding
  every worktree overlay. Branch overlays can be selected and synchronized afterwards.

## Verification

- Full automated suite: 1,550 passed, 8 skipped, 0 failed.
- An interrupted multi-batch build was resumed from its durable checkpoint without resubmitting
  any completed embedding input.
- A zero-filled `progress.json` regression fixture no longer breaks `index_status`.
