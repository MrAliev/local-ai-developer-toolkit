# LocalAi 0.1.20

[English version](0.1.20.md)

## Надёжность установщика

- Обновление теперь принимает оба поддерживаемых неизменяемых формата версии: только
  исполняемые файлы runtime и точный набор артефактов подписанного пакета с дополнительной
  копией launcher внутри версии. Неизвестные файлы и каталоги по-прежнему отклоняются.
- Windows-установщик восстанавливает отсутствующее или относительное process-level значение
  `windir` до создания первого WPF-окна. Это устраняет падение font cache в ограниченных
  окружениях запуска.

## Индексация

- Включены изменения 0.1.19 для возобновляемой многоязычной индексации: завершённые пакеты
  embeddings сохраняются при обрыве клиента или перезагрузке ПК, а `sync --base-only` не
  затрагивает оверлеи веток.
