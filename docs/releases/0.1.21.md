# LocalAi 0.1.21

[Русская версия](0.1.21.ru.md)

## Precise C# navigation

- Roslyn semantic indexes now emit type-level implementation relationships for direct
  `Class : IInterface` declarations.
- `find_implementations` and `find_relationships` can therefore navigate from an interface
  type to its implementing classes and back, instead of returning an empty result while
  definitions and references were already precise.
- A compiler-backed end-to-end regression test exercises the public navigation service from
  an interface declaration to its implementation.
