# LocalAi 0.1.46

[English version](0.1.46.md)

Этот релиз закрывает backlog, открытый прогоном 0.1.45 на чистой машине. Сквозная тема: то,
что инструментарий делает с машиной, теперь записывается, отменяется там, где отмена честна, и
называет себя прямо, когда ломается. Установка, остановившаяся на середине, больше не
оставляет состояние, которого никто не записал; строка сбоя больше не приходит анонимной;
индекс, не покрывший ничего, больше не называет себя точным.

**Этот релиз ничего не пересобирает.** Границы чанков, семантический формат и идентичность
поколения не менялись, поэтому существующий индекс остаётся действительным, и никакой
синхронизации, кроме обычной после коммита, не требуется.

## Установщик ведёт журнал и предлагает откат, который может честно выполнить

Мастер применяет настоящие, общесистемные изменения: установки winget, активированную версию,
файлы рантайма, регистрации MCP-клиентов. До сих пор прогон, упавший или отменённый на
середине, оставлял машину в состоянии, единственной записью о котором была строка в логе.

Теперь каждый прогон пишет журнал в `%LOCALAPPDATA%\LocalAi-installer-logs` — намерение до
каждого эффекта, атомарно и со сквозной записью, и исход после него, — поэтому мастер, убитый
посреди установки, всё равно оставляет запись. После неудачного или отменённого прогона
финишная страница предлагает **Roll back changes**; следующий запуск предлагает то же для
прогона, который не успел закончиться. Пока мастер работает, журнал держит живой замок,
поэтому второй мастер отличает убитый прогон от идущего в другом окне и никогда не предлагает
откатить работу на лету.

Откат отменяет только доказуемое: активация при обновлении возвращается через защищённый своп
указателя в launcher, а политика резидентности, запись запуска Ollama и файлы конфигурации
клиентов восстанавливаются, только пока их хэш совпадает с тем, что записал прогон. Что откат
не тронет, названо эффект за эффектом: установки winget и npm — общесистемное ПО, скачанные
модели живут в хранилище Ollama, а корень первой установки хранит данные рантайма, как только
запускается брокер. Успешный прогон пишет журнал и ничего больше.

## Установку стало проще начать и труднее сорвать

**Папка работает там, где GitHub недоступен.** Скачайте манифест, подпись и пакет на машине,
у которой есть доступ, положите все три в папку и укажите её установщику — или положите
установщик в эту папку, и он предложит путь сам. Папка не даёт доверия: манифест проверяется
тем же встроенным ключом, пакет — тем же SHA-256.

**Обязательны только Git и Ollama.** .NET SDK, Node.js, Python и два индексатора SCIP дают
точную навигацию каждый для своего языка, и любой можно пропустить — страница говорит, что
при этом теряется. Вместе это три-четыре гигабайта общесистемных установок — так себе
требование к тому, кому нужен семантический поиск по C#.

**winget проверяется перед каждым запуском.** Установщик убеждается, что исполняемый файл
принадлежит зарегистрированному пакету `Microsoft.DesktopAppInstaller`, лежит по пути, куда
могут писать только администраторы, и подписан Microsoft, — и запускает путь, который
разрешила проверка, перед каждой установкой, а не один раз при обнаружении.

**Заглушка не может уехать в релиз.** `--require-authenticode` отказывается подписывать, пока
политика издателя — заглушка, которой не может соответствовать ни один файл, вместо того
чтобы выпустить релиз, который отвергнет каждая машина.

## Недоступность Ollama — состояние ожидания, а не отказ

Работа остаётся в очереди, брокер повторяет попытки, а вызов, исчерпавший ожидание, говорит,
что Ollama не отвечает и по какому адресу, вместо голой отмены. Там, где установщик записал
проверенную Ollama, брокер поднимает её один раз — только записанный файл, никогда не
найденный в момент запуска, и никогда для адреса на другой машине.

## Индекс, не покрывший ничего, перестал называть себя точным

Репозиторий с C#, где семантика не покрыла ни одного файла, раньше завершал `localai sync`
тихим успехом, а `index_status` называл поколение точным, потому что `semantic.sidx`
существовал. Теперь `sync` говорит об этом, `--require-semantics` превращает предупреждение в
отказ для хука или шага CI, а `index_status` называет такое поколение эвристическим. Когда в
репозитории нет файла решения и проектный fallback загрузил одну точку входа, оставшиеся
проекты называются по именам — частичное покрытие больше не выглядит в точности как полное.

## Сбои называют себя

Непредвиденный сбой CLI печатает тип исключения и всю внутреннюю цепочку, а не одно внешнее
сообщение — голый `DllNotFoundException` раньше печатал ровно «Dll was not found.» и ничего
больше. Сбой workspace при семантической индексации называет свой вид и загружаемую точку
входа. Сбой Git называет причину, вместо того чтобы сворачивать таймаут, неудачный запуск и
ненулевой код в одно сообщение. `read_image` называет отсутствующую модель вместо общего
отказа, а задание, которое брокер так и не выполнил, говорит, почему.

## Документация описывает текущие факты

Живая документация — README, обзор для разработчиков, справочник инструментов — переписана по
текущему состоянию, на обоих языках, без нарратива «было — стало». Датированные записи,
которым больше не было места в дереве, — планы, проектные записки, старые заметки релизов,
бенчмарк-отчёты — удалены; git-история хранит их все. Добавлен кодекс поведения с маршрутом
жалобы, который не проходит через того, на кого жалуются.
