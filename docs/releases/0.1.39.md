# LocalAi 0.1.39

[Русская версия](0.1.39.ru.md)

What the tools tell an agent about themselves now matches what they do. No behaviour changed;
what changed is the text two of them ship.

## Two claims that were wrong on every installation

The `search_code` tool description said the corpus is "chunked by symbol (class, method,
property) rather than by file", and the managed instruction block written into `CLAUDE.md` and
`AGENTS.md` on every install said search matches "over Roslyn-aware chunks". Only C# is chunked
that way. Every other language goes through a sliding window over lines, which is why a
TypeScript hit is named for its file and line range rather than for a function.

The cost of that sentence is not cosmetic: an agent that believes it reads a windowed hit as a
broken index and expects a symbol it can hand to `find_references`. Both strings now state the
rule per language, and both READMEs and both tool inventories carry the same statement — what
earns its own vector in C#, what rides inside the type chunk instead, that generated C# is not
indexed at all, and that precise navigation is a separate layer which does parse TypeScript and
Python.

Extending symbol-level chunking to those languages is tracked as issue #82.

## A document for the people who use this, not those who change it

`docs/overview.ru.md` is a connected walkthrough with six diagrams: the queue and its three
visible properties, the routing catalogue and the experiment gate, how sources become chunks,
the trust boundary and what it covers, the token arithmetic with measured numbers, and the
recipes for a working day. Every claim in it was checked against the code, and its appendix
lists that check openly — including the three statements that did not survive it.

Russian only for now; the READMEs and the tool inventory remain the paired documents.

## Upgrading

Install with the GUI installer from this release. It stops the broker and the running MCP
servers itself, replaces them, and activates the new version. The managed instruction block in
`CLAUDE.md` and `AGENTS.md` is rewritten between its markers, so the corrected wording arrives
with the installation; anything you wrote outside those markers is preserved. Restart the client
to pick it up.
