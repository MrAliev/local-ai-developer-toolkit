# LocalAi 0.1.35

[English version](0.1.35.md)

Одно исправление, найденное тем, что на него наткнулись, а не тем, что его искали в коде.

## Брокер больше не удерживает каталог того, кто его запустил

Удаляли git worktree. `git worktree remove` снял его с учёта, а файлы остались на диске. Удалить их
не получалось ни из bash, ни из PowerShell, ни из проводника — каждый отвечал, что каталог занят
другим процессом, и не называл каким. Каталог освободился мгновенно, как только сняли процесс
брокера LocalAi.

Брокер стартует по требованию первого клиента, которому он понадобился, и живёт часами после того,
как этот клиент завершился. В его `ProcessStartInfo` не был задан рабочий каталог, поэтому он
наследовал каталог вызвавшего, — а процесс держит свой рабочий каталог открытым всё время жизни.
Тот каталог, в котором случайно оказался клиент в момент первого старта брокера, становился
неудаляемым на весь срок жизни брокера.

К worktree это не имело никакого отношения: точно так же удерживался **любой** каталог, из которого
брокер стартовал первым. И симптом никогда не указывал на брокера — падала операция над
репозиторием, а виновником был посторонний фоновый сервис, запущенный часами раньше из каталога, о
котором никто не думал.

Теперь брокер работает в собственном runtime root — там, куда он и так пишет. Каталог создаётся
до старта, чтобы самый первый запуск не падал на ещё не существующем пути.

## При обновлении

Исправление действует на брокеров, запущенных начиная с 0.1.35. Брокер, уже работающий из более
ранней версии, продолжает удерживать унаследованный каталог до следующего перезапуска — установка
этой версии его перезапускает.

## Проверка

Пустой `WorkingDirectory` — это и есть наследование, поэтому тест проверяет значение, а не
отсутствие симптома, и проверен так, как тест проверять положено: с убранным присваиванием он
падает и снова проходит после возврата.

Форма делегата старта не менялась, поэтому несколько сотен построенных на нём тестов не затронуты.

Полный прогон по девяти проектам: **1679 passed, 4 skipped, 0 failed**.
