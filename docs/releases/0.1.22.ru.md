# LocalAi 0.1.22

[English version](0.1.22.md)

## Миграция семантической generation

- Повышена версия семантического контракта после добавления в 0.1.21 отношений реализации
  типов C#.
- Существующие репозитории теперь автоматически получают новую неизменяемую generation,
  а не переиспользуют семантический граф, созданный версией 0.1.20.
- Неизменившийся лексический корпус и embeddings допускаются к повторному использованию,
  поэтому миграция не теряет уже выполненную обработку embeddings.
