# LocalAi 0.1.26

[English version](0.1.26.md)

## Надёжная мультиязычная семантическая индексация

- Семантическая генерация больше не публикуется при ошибке обязательного внешнего SCIP-адаптера:
  предыдущая current-генерация остаётся доступной вместо сохранения неполного результата.
- Репозитории только с JavaScript и без `tsconfig.json` индексируются в изолированном временном
  workspace без записи сгенерированной конфигурации в сам репозиторий.
- Идентификаторы локальных TypeScript/JavaScript- и C#-символов в Windows стали стабильными и
  больше не содержат случайные пути snapshot или временного workspace.
- При технической загрузке Roslyn отключён NuGet-аудит для restore индексатора, поэтому проекты,
  превращающие audit warnings в ошибки, сохраняют точную C#-семантику; обычные build и restore
  репозитория не меняются.
- Версия семантической генерации 10 принудительно пересобирает исправленный sidecar в уже
  подключённых репозиториях.

Перед PR проверены полный набор тестов, подписанный пакет, чистый смешанный TypeScript/Python-
репозиторий и IntelWash: лексический и мультиязычный семантический поиск, definitions,
implementations, references и relationships.
