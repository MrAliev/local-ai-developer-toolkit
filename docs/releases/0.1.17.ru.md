# LocalAi 0.1.17

[English version](0.1.17.md)

## Исправлено

- Roslyn MSBuild BuildHost встроен в self-contained EXE CodeSearch. Семантический индекс
  теперь обновляется из установленного релиза без внешних файлов публикации.
- Git-хуки, установленные `localai hooks install`, обновляют индекс после commit, checkout,
  merge (включая подтянутый merge PR) и переписывания истории.

## Проверка

- Полный набор автотестов: 1 540 пройдено, 8 пропущено, 0 ошибок.
- Опубликованный `localai.exe`, запущенный без внешних каталогов `BuildHost-*`, успешно
  выполнил `localai sync` и построил актуальную базу и overlay рабочего дерева.
