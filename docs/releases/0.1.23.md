# LocalAi 0.1.23

[Русская версия](0.1.23.ru.md)

## Complete semantic indexing prerequisites

- The installer now detects and provisions .NET SDK 10, Node.js 20, Python 3.10+,
  `@sourcegraph/scip-typescript@0.4.0`, and `@sourcegraph/scip-python@0.6.6`.
- Newly installed command shims and registry PATH updates are detected without manual setup.
- Repository sync restores NuGet dependencies before Roslyn loads a solution, so Aspire and
  other SDK-based projects are included in exact C# navigation.
- Existing repositories migrate to semantic generation 5 while retaining reusable lexical
  and embedding work.
