# LocalAi 0.1.27

[Русская версия](0.1.27.ru.md)

## Detect installed npm SCIP shims correctly

- The installer environment check now follows Windows `PATHEXT` precedence and probes `.cmd`
  command shims before adjacent extensionless POSIX npm scripts.
- Already installed `scip-typescript` and `scip-python` dependencies are therefore reported as
  available instead of misleading `Not found` warnings on every upgrade.
- Regression coverage verifies candidate ordering, unchanged explicit/non-Windows commands, real
  installed npm shim resolution, and the exact `--version` process probes used by the installer.

This corrects the prerequisite-screen regression that remained in 0.1.26; runtime semantic
indexing already used the correct Windows shim resolution.
