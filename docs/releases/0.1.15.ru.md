# LocalAi 0.1.15

[English version](0.1.15.md)

## Главное

- Добавлен snapshot-bound семантический индекс `semantic.sidx` рядом с векторным индексом.
- Добавлены точные Go to definition, Find references, Find implementations и relationship queries.
- Добавлены Roslyn-индексация C# и адаптеры WPF, WinUI, .NET MAUI и Avalonia XAML.
- Добавлены ограниченные адаптеры `scip-typescript` и `scip-python`, а также настраиваемые live LSP
  sessions для TypeScript/JavaScript, Python, HTML и C#.
- Добавлены компактные semantic overlays dirty worktree с deletion tombstones.
- Для неподдерживаемых языков добавлен ограниченный syntax/text fallback с явной точностью
  `Heuristic`.
- Добавлена marker-based оценка correctness, latency, памяти и размера SIDX.
- Idle keep-alive модели по умолчанию равен нулю: локальная модель выгружается, как только в её
  очереди не остаётся совместимой работы. Глобальная policy остаётся настраиваемой без пересборки.

## Конфигурация

- `%LOCALAPPDATA%\LocalAi\policy.json`: residency модели и idle keep-alive.
- `%LOCALAPPDATA%\LocalAi\semantic-indexing.json`: SCIP adapters и лимиты parser/process.
- `%LOCALAPPDATA%\LocalAi\language-servers.json`: live LSP servers и transport limits.
- `%LOCALAPPDATA%\LocalAi\semantic-navigation.json`: heuristic fallback и scan limits.

Все файлы читаются во время работы; их изменение не требует пересборки приложения.

## Baseline проверки

- Semantic navigation acceptance: 4/4 cases.
- Полная solution suite: 1 536 успешно; 8 environment-dependent fixtures пропущены.
- Self-contained win-x64 preflight: подписанный package manifest и проверка installer package — OK.
- Изолированный fresh-install activation test: успешно.
- Измерения latency, памяти и размера индекса находятся в
  [semantic-navigation-evaluation.ru.md](../semantic-navigation-evaluation.ru.md).

Подписанный `release-manifest.json` генерируется из финального пакета и не хранится в Git, потому
что он связывает точные package URI, размер, SHA-256, compatibility contract и immutable version
directory.
