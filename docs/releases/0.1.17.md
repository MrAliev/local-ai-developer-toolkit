# LocalAi 0.1.17

[Русская версия](0.1.17.ru.md)

## Fixed

- Bundled the Roslyn MSBuild build hosts into the self-contained CodeSearch executables.
  Semantic index refresh now works from an installed release without loose deployment files.
- Git hooks installed by `localai hooks install` can refresh semantic indexes after commit,
  checkout, merge (including a pulled PR merge), and history rewrite.

## Verification

- Full automated suite: 1,540 passed, 8 skipped, 0 failed.
- An EXE-only published `localai sync` completed and produced the current base generation
  and worktree overlay without external `BuildHost-*` directories.
