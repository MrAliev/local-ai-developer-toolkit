# LocalAi 0.1.24

[English version](0.1.24.md)

## Надёжная SCIP-индексация Python в Windows

- Установщик применяет к точному бандлу `@sourcegraph/scip-python@0.6.6` закреплённый
  compatibility patch с проверкой SHA-256 и проверяет установленную команду перед успешным
  завершением.
- Патч исправляет некорректное регулярное выражение для разделителя путей Windows и не даёт
  псевдониму Microsoft Store `python3.exe` приоритет над установленным Python.
- Процессы SCIP-индексаторов получают актуальный системный и пользовательский PATH, поэтому
  новые зависимости доступны без ручного редактирования PATH.
- Установщик не изменяет пакет с неизвестной версией или содержимым и явно сообщает об ошибке.
