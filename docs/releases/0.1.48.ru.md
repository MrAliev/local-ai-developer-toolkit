# LocalAi 0.1.48

[English version](0.1.48.md)

Одно исправление, найденное проверкой 0.1.47 на живой машине: правило навигации с колонкой 0,
вышедшее в том релизе, не могло сработать для C# — языка, ради которого писалось.

**Сам по себе этот релиз ничего не пересобирает.** Границы чанков, семантический формат и
идентичность поколения не менялись, существующий индекс остаётся действительным. Исправление
ниже попадает в *содержимое* семантического индекса: колонка 0 начнёт разрешаться на строках
C# со следующей сборки поколения после установки — то есть с обычной синхронизации после
вашего следующего коммита.

## Определения C# несут свой объемлющий диапазон

0.1.47 научил колонку 0 разрешаться в объемлющее объявление строки по вложенности объемлющих
диапазонов. Правило работало — там, где объемлющий диапазон существовал. Импортёры SCIP
проносят их для TypeScript и Python; индексатор Roslyn не писал их вовсе, поэтому для C#
однострочная сигнатура метода по-прежнему объявляла «две вещи», сравнивать было нечем, и
колонка 0 деградировала в текстовую эвристику, тогда как колонка идентификатора отвечала
Precise.

Определения, которые строит индексатор Roslyn, теперь несут полный span узла объявления как
объемлющий диапазон. Диапазоны сами сохраняют гарантию для соседей: каждый декларатор в
`const a = f(), b = g()` покрывает только себя, а узел параметра — только параметр, поэтому
ни один из них не может претендовать на всю строку. Формат индекса хранил это поле всегда —
форма не меняется, а регрессионный тест нарочно сквозной: настоящий исходник C# через
настоящий индексатор в настоящий резолвер, колонка 0 на входе, метод на выходе.
