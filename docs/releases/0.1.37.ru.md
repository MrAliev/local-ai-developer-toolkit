# LocalAi 0.1.37

[English version](0.1.37.md)

Разбор логов больше не ограничен одним контекстом модели или объёмом текста, который можно
целиком загрузить в память.

## Логи любой длины

`triage_log` теперь принимает ровно один источник: абсолютный путь к файлу или переданный напрямую
текст лога. Файлы читаются потоком, а не целиком. Broker проверяет настроенные контексты от большего
к меньшему и выбирает наибольшую пару модель/контекст, для которой на текущей машине доказана
полная резидентность в VRAM.

Каждый фрагмент анализируется через общую FIFO-очередь строго последовательно. Частичные результаты
объединяются ограниченной иерархической свёрткой, поэтому реализация не хранит весь лог или
неограниченный список сводок. Перекрытие сохраняет ошибки на границе фрагментов, а свёртка удаляет
повторяющиеся свидетельства.

## Настройка во время работы

Перед каждым вызовом профиль читается из `log-triage.json` в runtime root LocalAi. Можно ограничить
контекст и размер фрагмента, зарезервировать место для ответа, настроить перекрытие, частичные
сводки и оценку символов на токен. Отсутствующий, повреждённый или неподдерживаемый файл политики
заменяется безопасными значениями по умолчанию. После редактирования не нужны ни пересборка, ни
перезапуск процесса.

Настроенный контекст — только верхний предел. Он не отменяет full-VRAM preflight: если большой
контекст не помещается, LocalAi перебирает меньшие размеры из каталога, а не выгружает часть модели
в системную память без предупреждения.

## Обновление

Установите версию GUI-инсталлятором из этого релиза. Установка перезапустит broker и обновит
управляемые инструкции MCP. Существующие установки настраивать не требуется: новые значения по
умолчанию применяются автоматически.

## Проверка

Полный набор решения прошёл 1 766 тестов с четырьмя платформенными пропусками. Живой MCP-прогон
обработал 120 087 символов как три последовательных фрагмента с доказанным контекстом 32 768,
сохранил ошибки на обоих концах входа и после завершения не оставил ни одной модели в памяти.
