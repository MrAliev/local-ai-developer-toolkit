# LocalAi 0.1.15

[Русская версия](0.1.15.ru.md)

## Highlights

- Added snapshot-bound semantic indexing (`semantic.sidx`) alongside the vector index.
- Added precise Go to definition, Find references, Find implementations, and relationship queries.
- Added Roslyn C# indexing and WPF, WinUI, .NET MAUI, and Avalonia XAML adapters.
- Added bounded `scip-typescript` and `scip-python` adapters and configurable live LSP sessions for
  TypeScript/JavaScript, Python, HTML, and C#.
- Added compact dirty-worktree semantic overlays with deletion tombstones.
- Added an explicitly `Heuristic` bounded syntax/text fallback for unsupported languages.
- Added marker-based correctness, latency, memory, and SIDX-size evaluation.
- Changed the default model idle keep-alive to zero: a resident local model is unloaded as soon as
  its queue has no compatible work. The policy remains installation-wide and configurable without
  rebuilding LocalAi.

## Configuration

- `%LOCALAPPDATA%\LocalAi\policy.json`: model residency and idle keep-alive.
- `%LOCALAPPDATA%\LocalAi\semantic-indexing.json`: SCIP adapters and parser/process limits.
- `%LOCALAPPDATA%\LocalAi\language-servers.json`: live LSP servers and transport limits.
- `%LOCALAPPDATA%\LocalAi\semantic-navigation.json`: heuristic fallback and scan limits.

All files are read at runtime; changing them does not require rebuilding the application.
