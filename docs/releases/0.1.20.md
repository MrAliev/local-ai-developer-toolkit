# LocalAi 0.1.20

[Русская версия](0.1.20.ru.md)

## Installer reliability

- Upgrades now accept both supported immutable version layouts: runtime executables only,
  and the exact signed-package artifact set that also contains a versioned launcher copy.
  Unknown files and directories are still rejected.
- The Windows installer repairs a missing or relative process-level `windir` value before
  WPF creates its first window, preventing the font-cache startup crash seen in constrained
  launcher environments.

## Indexing

- Includes the resumable multilingual indexing work from 0.1.19: completed embedding
  batches survive client interruption or a PC restart, and `sync --base-only` leaves branch
  overlays untouched.
