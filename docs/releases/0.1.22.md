# LocalAi 0.1.22

[Русская версия](0.1.22.ru.md)

## Semantic generation migration

- Bumps the semantic generation contract after 0.1.21 added C# type implementation
  relationships.
- Existing repositories now receive a new immutable generation automatically instead of
  reusing a semantic graph produced by 0.1.20.
- The unchanged lexical and embedding corpus remains eligible for reuse, so the migration
  does not discard completed embedding work.
