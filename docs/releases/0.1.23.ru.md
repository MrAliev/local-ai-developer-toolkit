# LocalAi 0.1.23

[English version](0.1.23.md)

## Полный набор зависимостей семантической индексации

- Установщик теперь обнаруживает и устанавливает .NET SDK 10, Node.js 20, Python 3.10+,
  `@sourcegraph/scip-typescript@0.4.0` и `@sourcegraph/scip-python@0.6.6`.
- Новые command shim и изменения PATH из реестра обнаруживаются без ручной настройки.
- Перед загрузкой solution через Roslyn команда синхронизации восстанавливает NuGet-зависимости,
  поэтому Aspire и другие SDK-проекты входят в точную C#-навигацию.
- Существующие репозитории мигрируют на semantic generation 5 с переиспользованием готовой
  лексической индексации и embeddings.
