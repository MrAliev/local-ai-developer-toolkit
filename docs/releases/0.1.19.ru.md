# LocalAi 0.1.19

[English version](0.1.19.md)

## Исправлено

- Базовая и веточная embedding-индексация CodeSearch теперь сохраняет каждый завершённый batch
  в атомарный write-through checkpoint. После обрыва процесса или перезагрузки компьютера
  следующий sync восстанавливает эти векторы и пересчитывает только активный batch.
- Прогресс репозитория сбрасывается на диск до атомарной замены файла. Повреждённый или
  обрезанный JSON прогресса считается недоступным статусом и больше не ломает CodeSearch MCP.

## Добавлено

- `localai sync --base-only` публикует новую базовую генерацию без автоматической переиндексации
  overlays всех worktree. Нужные ветки можно выбрать и синхронизировать после базы.

## Проверка

- Полный набор автотестов: 1 550 пройдено, 8 пропущено, 0 ошибок.
- Прерванная многошаговая индексация продолжилась из durable checkpoint без повторной отправки
  уже завершённых embedding-входов.
- Регрессионный fixture с нулевым `progress.json` больше не ломает `index_status`.
