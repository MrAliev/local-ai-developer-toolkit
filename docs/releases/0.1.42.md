# LocalAi 0.1.42

[Русская версия](0.1.42.ru.md)

TypeScript and Python are chunked by symbol. A hit in a `.ts` or `.py` file is a definition
with a name, not `payments.ts [3/10]` with a boundary wherever line 48·k happened to fall.

**This release rebuilds every repository's index once.** Chunk boundaries are part of the
generation identity, so the first sync after installing it builds a new base generation from
scratch. Read the upgrading section before you start it.

## What a hit is now

C# has been chunked by syntax since the beginning; everything else was a 60-line window with
12 lines of overlap and no idea what it had just cut through. The window did not fail loudly —
it produced vectors describing the tail of one function and the head of the next, which is the
kind of wrongness that only ever shows up as worse results.

TypeScript and Python now cut on the definition boundaries the external indexers report. A
definition becomes a chunk carrying its real symbol, signature and line span. A definition that
contains others keeps its own lines and lists its children by their first line, the way a C#
type chunk lists member signatures rather than repeating bodies, so no line is embedded twice.

Everything no definition covers keeps the window: imports, module-level statements, the gap
between two functions. Nothing goes unindexed, and nothing is glued onto a neighbouring symbol.

Two shapes deliberately keep the window because `scip-typescript` reports no body for them: a
definition declared inside a function body, and a declaration whose initialiser is a call —
which is what `export const X = memo(() => …)` is. That was measured before any of this was
built, in issue #87, rather than assumed from the SCIP schema.

If the external indexer is missing, disabled by policy, or fails, the file chunks exactly as it
did before. That path is covered by a test that compares the fallback output chunk for chunk
against the previous chunker.

## What it measures

On a 2 653-file React repository, twelve answerable natural-language cases, the same commit
indexed both ways:

| | Before | After |
|---|---:|---:|
| Precision@5 | 0.116667 | 0.116667 |
| Recall@10 | 0.750000 | 0.750000 |
| Mean first relevant rank | 5.500000 | 4.916667 |
| Response characters | 70 245 | 66 087 |
| TypeScript/Python hits naming a symbol | 0 of 86 | 33 of 85 |
| Source lines those hits span | 3 819 | 2 232 |

Precision and recall did not move. On that corpus the right file was already being found; what
changed is what comes back with it — half a rank earlier, 5.9% fewer characters, and 42% fewer
source lines dragged along with the answer. The full table, including why the cases name a file
and no symbol, is in `docs/codesearch-evaluation.md`.

## Upgrading

Install with the GUI installer from this release, then run a sync per repository. The first one
rebuilds the base generation.

Budget for it. On that same React repository the corpus grew 75% — 3 471 chunks to 6 079 —
because a definition that used to share a window now has its own vector, and the rebuild
embedded all of them in about seven and a half minutes. A repository the size of a large C#
solution is on the order of an hour. `index_status` reports it as a build in progress with a
live count and ETA, which is what it is: a deliberate rebuild, not drift.

Nothing else needs re-running. Branch overlays are rebuilt on the same sync and are cut on the
same boundaries as the base generation, so a file changed on a branch no longer has a different
chunk shape from the same file in the mainline.

## Verification

The complete solution ran 1 813 tests: 1 809 passed and four skipped for platform reasons.

Two of them run the installed `scip-typescript` and `scip-python` against fixtures and assert
what each reports a body for — including that scip-typescript reports none for a definition
inside a function body. An adapter upgrade that changes that fails a test rather than silently
moving every chunk boundary in the corpus.

Two more read the sync command's own source to assert that the semantic phase precedes
embedding, for base generations and for overlays. The invariant has no runtime seam short of an
integration run with a broker, a Roslyn workspace and both external indexers, and swapping the
blocks back would otherwise read as a harmless tidy-up.

`codesearch evaluate` also stopped failing on any corpus whose cases all have an answer: a rate
over an empty set is reported as null instead of NaN, which is not JSON and used to kill the run
after every query had already been embedded.
