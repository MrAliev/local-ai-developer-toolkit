# LocalAi 0.1.24

[Русская версия](0.1.24.ru.md)

## Reliable SCIP Python indexing on Windows

- The installer now applies a pinned, SHA-256-verified compatibility patch to the exact
  `@sourcegraph/scip-python@0.6.6` bundle and verifies the installed command before reporting
  success.
- The patch fixes the invalid Windows path-separator regular expression and prevents the
  Microsoft Store `python3.exe` alias from taking precedence over an installed Python runtime.
- SCIP indexer processes receive the current machine and user PATH, so prerequisites installed
  after the parent application started are available without manual PATH edits.
- Unknown package bytes or versions are never modified; the installer fails visibly instead.
