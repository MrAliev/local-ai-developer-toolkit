# LocalAi 0.1.25

[Русская версия](0.1.25.ru.md)

## Run npm SCIP shims correctly on Windows

- SCIP executable discovery now follows Windows command-extension precedence and selects the
  npm-generated `.cmd` shim before the adjacent extensionless POSIX shell script.
- This fixes `scip-typescript` startup during real repository synchronization while retaining
  the SCIP Python compatibility and fresh-PATH fixes from 0.1.24.
- A Windows regression test reproduces the exact npm file layout and verifies that semantic
  output is produced through the `.cmd` shim.
