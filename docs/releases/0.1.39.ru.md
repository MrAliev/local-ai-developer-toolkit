То, что инструменты сообщают о себе агенту, снова совпадает с тем, что они делают. Поведение не

## Два утверждения, неверных на каждой установке

Описание инструмента `search_code` гласило, что корпус «нарезан по символам (класс, метод,
свойство), а не по файлам», а управляемый блок инструкций, который установщик пишет в `CLAUDE.md`
и `AGENTS.md`, — что поиск работает «по Roslyn-aware чанкам». Так нарезан только C#. Все остальные
языки проходят через скользящее окно по строкам, поэтому результат по TypeScript называет файл и
диапазон строк, а не функцию.

Цена этой фразы не косметическая: агент, поверивший ей, читает оконный результат как поломку
индекса и ждёт символ, который можно передать в `find_references`. Обе строки теперь формулируют
правило по языкам, и то же самое сказано в обоих README и обоих перечнях инструментов: что
получает собственный вектор в C#, что вместо этого едет внутри чанка типа, что сгенерированный C#
не индексируется вовсе и что точная навигация — отдельный слой, который TypeScript и Python как раз
разбирает.

Распространение посимвольной нарезки на эти языки отслеживается задачей #82.

## Документ для тех, кто этим пользуется, а не меняет

`docs/overview.ru.md` — связный разбор с шестью схемами: очередь и три её видимых свойства, каталог
маршрутизации и порог эксперимента, как исходники превращаются в чанки, граница недоверия и что она
покрывает, арифметика токенов с измеренными числами и рецепты рабочего дня. Каждое утверждение в нём
сверено с кодом, а приложение перечисляет эту сверку открыто — включая три утверждения, которые её
не прошли.

Пока только на русском; парными документами остаются README и перечень инструментов.

## Обновление

Установите версию GUI-инсталлятором из этого релиза. Он сам останавливает broker и работающие
MCP-серверы, заменяет их и активирует новую версию. Управляемый блок инструкций в `CLAUDE.md` и
`AGENTS.md` переписывается между своими маркерами, поэтому исправленные формулировки приезжают
вместе с установкой; всё, что написано вне маркеров, сохраняется. Перезапустите клиент, чтобы он
подхватил изменения.
