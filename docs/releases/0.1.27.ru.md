# LocalAi 0.1.27

[English version](0.1.27.md)

## Корректное обнаружение установленных npm SCIP shim

- Проверка окружения установщика теперь соблюдает порядок Windows `PATHEXT` и проверяет `.cmd`
  shim раньше соседнего extensionless POSIX-скрипта npm.
- Уже установленные `scip-typescript` и `scip-python` отображаются доступными вместо ложного
  предупреждения `Not found` при каждом обновлении.
- Регрессионные тесты проверяют порядок кандидатов, неизменность явных и non-Windows-команд,
  разрешение реально установленных npm shim и те же `--version`-запуски, которые выполняет
  установщик.

Версия исправляет регрессию экрана prerequisites, оставшуюся в 0.1.26; runtime-индексация уже
использовала корректное разрешение Windows shim.
