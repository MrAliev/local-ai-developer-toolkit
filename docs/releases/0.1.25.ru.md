## Корректный запуск npm SCIP shim в Windows

- Поиск SCIP-команд теперь соблюдает приоритет расширений Windows и выбирает созданный npm
  `.cmd` shim раньше соседнего POSIX-скрипта без расширения.
- Это исправляет запуск `scip-typescript` при реальной синхронизации репозитория и сохраняет
  исправления SCIP Python и актуального PATH из версии 0.1.24.
- Регрессионный Windows-тест воспроизводит точную структуру файлов npm и проверяет получение
  семантического индекса через `.cmd` shim.
