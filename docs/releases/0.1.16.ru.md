# LocalAi 0.1.16

[English version](0.1.16.md)

## Hotfix

- Direct embedding, direct chat и native model requests теперь регистрируют используемую модель
  как resident.
- При пустой очереди broker проверяет backend на наличие управляемых idle-моделей, даже если
  предыдущий запрос не оставил resident-маркер.
- При стандартной policy `IdleModelKeepAliveSeconds=0` embedding-модель CodeSearch выгружается
  сразу после исчезновения совместимой работы из очереди, а не ждёт собственного expiration
  Ollama.

## Причина

Idle unloading использовал resident-маркер routed chat как предварительное условие. Direct
embedding выполнялся отдельным путём и не обновлял этот маркер, поэтому пустая очередь выглядела
так, будто модель не загружена. Hotfix отслеживает все direct-запросы с моделью и дополнительно
сохраняет защитную проверку backend при пустой очереди.

## Проверка

- Добавлены regression-тесты для direct Embed, Native Generate и очистки пустой очереди без
  resident-маркера.
- Broker test suite: 361 успешно.
- Полная solution suite: 1 539 успешно; 8 environment-dependent fixtures пропущены.
