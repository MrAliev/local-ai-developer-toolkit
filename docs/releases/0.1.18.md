# LocalAi 0.1.18

[Русская версия](0.1.18.ru.md)

## Fixed

- Exact lexical matches now inspect chunk contents, not only symbol, signature, and path
  metadata. Python, JavaScript, TypeScript, HTML, XAML, and every other generic-text language
  therefore participate in lexical and hybrid search.
- XML and HTM files are now included in generic-text indexing.

## Upgrade note

- The CodeSearch index format is now v4. The first synchronization after upgrading performs a
  one-time full rebuild so existing chunks receive their lexical text. Later synchronizations
  remain incremental.

## Verification

- Full automated suite: 1,547 passed, 8 skipped, 0 failed.
- A real v3 index was migrated to v4: 425 files and 4,669 base chunks, followed by an overlay
  with 8 files and 100 chunks.
- An exact PowerShell body identifier from the resulting index ranked its defining chunk first.
