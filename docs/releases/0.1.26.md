# LocalAi 0.1.26

[Русская версия](0.1.26.ru.md)

## Reliable multilingual semantic indexing

- A semantic generation is no longer published when a required external SCIP adapter fails;
  the previous current generation remains usable instead of caching an incomplete result.
- JavaScript-only repositories without a `tsconfig.json` are indexed through an isolated
  synthetic workspace, without writing generated configuration into the repository.
- Windows TypeScript/JavaScript and C# local symbol identifiers are now stable and no longer
  contain random snapshot or temporary-workspace paths.
- Roslyn workspace loading disables NuGet vulnerability auditing for the indexing-only restore,
  so repositories that promote audit warnings to errors retain precise C# semantics while their
  normal build and restore policy remains unchanged.
- Semantic generation version 10 forces existing repositories to rebuild the corrected sidecar.

Pre-release acceptance covered the complete test suite, a signed packaged build, a clean mixed
TypeScript/Python repository, and IntelWash lexical, multilingual semantic, definition,
implementation, reference, and relationship navigation.
