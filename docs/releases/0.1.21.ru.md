# LocalAi 0.1.21

[English version](0.1.21.md)

## Точная навигация C#

- Семантический индекс Roslyn теперь создаёт отношения реализации уровня типов для прямых
  объявлений `Class : IInterface`.
- `find_implementations` и `find_relationships` теперь переходят от интерфейса к реализующим
  его классам и обратно, вместо пустого результата при уже работающих точных определениях
  и ссылках.
- Добавлен сквозной регрессионный тест на базе компилятора: от объявления интерфейса через
  публичный сервис навигации к реализации.
