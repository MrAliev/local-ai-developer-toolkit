# LocalAi 0.1.47

[English version](0.1.47.md)

Три исправления, найденные проверкой 0.1.46 на живой машине: маршрутизируемая модель, невидимо
валившая половину своих заданий; навигационное сокращение, отказывавшее ровно тем попаданиям,
ради которых написано; и релизная команда, чей первый боевой прогон умер внутри Git-хука.

**Этот релиз ничего не пересобирает.** Границы чанков, семантический формат и идентичность
поколения не менялись; существующий индекс остаётся действительным, а исправление навигации
ниже читает диапазоны, которые этот индекс уже хранит.

## qwen3.5:9b отвечает, а не додумывает окно до конца

Все технические отказы за месяц телеметрии — шестнадцать заданий, 48% от общего числа у этой
модели — принадлежали qwen3.5:9b, и fallback гасил каждый настолько тихо, что закономерность
пряталась за приемлемыми процентами успеха по профилям. Причина: модель рассуждает по
умолчанию, а на малых ступенях контекста, которые маршрутизация предпочитает для извлечения,
классификации и коротких сводок, одни только рассуждения исчерпывают окно — полный `thinking`,
пустой `content`, отвергнутый ответ, fallback.

Каталог маршрутизации теперь помечает модели, чьи рассуждения Ollama умеет выключать, и брокер
шлёт `think: false` ровно для них — сегодня это одна qwen3.5:9b. У gpt-oss рассуждения
отключить нельзя вовсе, поэтому безусловный флаг обменял бы пустые ответы одной модели на
отвергнутые запросы другой. Native-passthrough не тронут.

Месяц невидимости — сам по себе дефект. `localai telemetry` теперь печатает одну строку
`attention`, когда модель с достаточным числом заданий валит не меньше четверти из них и
владеет не меньше чем половиной всех записанных отказов: цифры всегда были в таблицах, но
увидеть закономерность можно было только сверкой двух из них.

## Колонка 0 ведёт к методу, а не к отказу

Мост от поиска к навигации обещает, что начальная строка попадания навигирует как есть, с
колонкой 0. Реализовано это было правилом «ровно одно объявление», и в C# обещание не
выполнялось как раз для главной аудитории: однострочная сигнатура объявляет и метод, и его
параметры, поэтому колонка 0 на попадании в метод проваливалась в уведомление о деградации.

Параметр — не сосед метода, а вложенный в него символ. Колонка 0 теперь разрешается в то
объявление, чей объемлющий диапазон содержит все остальные объявления строки, — проверка
вложенности по диапазонам, которые семантический индекс уже хранит, поэтому ответ честно
сохраняет метку `Precise`. Строка настоящих соседей (`const a = f(), b = g()`) по-прежнему
отказывает, как и строка, чей кандидат-контейнер не сообщил объемлющего диапазона: отсутствие
диапазона деградирует в прежний отказ, а не в догадку.

## Релизная команда больше не вызывается на Git-хуки

Первый боевой прогон `release --version 0.1.46` умер внутри `git switch --create`:
post-checkout-хук LocalAi начал синхронизацию индекса чужого worktree, и двухминутный
Git-бюджет команды истёк, меряя очередь эмбеддингов вместо Git, — после того как ветка
появилась, и до того как заметки были закоммичены. Каждая Git-операция релизной команды теперь
несёт пустой путь хуков; следующая настоящая Git-операция пользователя хуки по-прежнему
запускает, поэтому индекс не отстаёт. Этот релиз — первое полевое испытание исправления: его
собственная подготовка прошла от начала до конца.
