# LocalAi 0.1.36

[Русская версия](0.1.36.ru.md)

Two things this installation could not tell you about itself, and one number that had to be typed
in six places to cut a release.

## `localai doctor`

The sequence anyone verifying an installation used to run by hand: which version the pointer
names and whether its binaries are all there, the stable entry point, whether the broker is
alive, the queue and quarantine, the policies actually in effect, and the repository index.

It exists because that sequence was being retyped, and the parts most worth checking are the ones
that fail silently. A policy file that stopped parsing does not announce itself — it falls back
to safe defaults and the installation quietly stops doing what it was configured to do.

Read-only, and it starts nothing, including the broker: a diagnostic that launches the broker to
see whether the broker is running answers a question nobody asked. The exit code is non-zero only
for a real fault, so a stopped broker is a note rather than a failure.

## `localai telemetry`

Every delegated job has been leaving a record under the runtime root for thirty days — the
routing decision, whether the model was cold, whether the fallback was taken, what the queue and
the execution cost, what the job saved. Nothing could read any of it. The experiment report
covers the handful of jobs belonging to a running experiment; the rest were written, retained,
pruned on schedule and never once looked at.

The command summarises them: outcomes, cold against warm, fallback share, queue and execution
latency at the median and the p90, and the estimated cloud spend avoided — each also broken down
by model and by task profile.

Latencies are nearest-rank percentiles, so every duration printed is one some job really took.
Savings are bands, never totals: the estimator counts characters, there is no live token counter
in this system, and summing a hundred thousand estimates does not make them exact.

The first run on a month of real data was not flattering, which is the point of having it: 61% of
jobs paid for a cold load, 31% took the fallback, and the longest a job waited in the queue was
over six minutes.

## The release is one command now

Cutting a release was six steps, and the same version had to be typed identically in four places
— both note filenames, both headings, the publish script, the tag — with the commit repeated in
two more. Nothing compared any of them, and every disagreement produces a package that verifies
its signature, installs cleanly, and is not what the tag names.

`localai-release-signer release --version X` checks the version is ahead of every published tag,
scaffolds the notes and stops. `--publish`, from the merged commit on main, refuses a dirty tree,
a branch other than main, a commit origin has not seen, a commit without a green build, a version
already tagged, and notes still carrying the scaffold's TODO — then builds, signs, compares the
manifest against the release being published, and only then tags and uploads.

Signing stays on the machine that holds the key, as it always has. The whole release now runs
there, and CI is asked only whether the commit is green.

## Upgrading

`localai doctor` and `localai telemetry` are available as soon as this version is installed.
Nothing needs configuring, and the telemetry command reports whatever the broker has already
recorded — including from earlier versions, since the record format did not change.

Installing restarts the broker.

## Verification

The suite is 1760 tests, and the ones added here were checked the way this project checks tests:
by breaking what they claim and confirming they fail. Nine did not survive that and were
rewritten — among them a check that counted the same condition twice and passed because both
totals happened to be one, and a manifest reader with no test at all whose strictness options
turned out to do nothing.

Three tests that had been failing on the CI runner for reasons of timing were fixed at the cause
rather than by raising their deadlines: one had its two timeouts passed in the wrong order and
had been "fixed" three times by raising a number nothing read; one derived a process id from a
file the child process wrote, making its budget a bet on how quickly PowerShell starts; one
compared a cancellation against a stopwatch rather than against the budget it was meant to beat.
